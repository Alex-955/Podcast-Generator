ONBOARDING · 3 步下载即用

免装 Node.js，下载桌面客户端双击开播

v1.0 桌面正式版内置运行环境，支持自动端口避让（3456–3475）、本地配置持久化与一键导入旧版便携目录，无需命令行或编程环境。

1

下载对应系统桌面安装包

macOS 请按芯片选择 Apple Silicon (.dmg) 或 Intel (.dmg)，Windows 选择 64 位安装版 (.exe)；亦可在 GitHub Releases 获取便携 Node.js 版。

2

安装并首次放行开源未签名版

将「拾声集」拖入「应用程序」即可运行；首次打开若提示无法验证开发者或已损坏，前往「系统设置 → 隐私与安全性 → 仍要打开」，或终端执行 xattr -cr "/Applications/拾声集.app"。

双击 InkCast-v1.0.0-win-x64-setup.exe 完成安装；首次运行若遇「Windows 已保护你的电脑」提示，点击「更多信息 → 仍要运行」即可。

3

填好密钥、选风格，支持逐句微调

填入 API Key（语音可用免费 Edge 先试听），可选深度主讲 / 轻松对谈 / 正反交锋三种风格；生成后可逐句改词秒级重合成，也可一键导入旧版便携目录。

macOS Gatekeeper：提示“无法验证开发者”或“已损坏”

因开源项目未购买商业 Apple 开发者签名证书，系统会首次拦截。请前往「系统设置 → 隐私与安全性 → 仍要打开」，或在终端运行 xattr -cr "/Applications/拾声集.app" 即可正常启动。

Windows SmartScreen：提示“Windows 已保护你的电脑”

因开源安装包未购买商业代码签名证书，SmartScreen 会首次提醒。点击弹窗里的「更多信息」→「仍要运行」即可正常安装与启动，亦可先对照 SHA256SUMS.txt 校验安装包哈希。

PRIVACY & ROADMAP · 隐私边界与演进路线

纯本机可审计架构，每一步规划都透明写清

所有密钥与音频均留在你的电脑里，v1.0 桌面正式版现已发布，并清晰列出后续演进方向。

凭据零落盘

API Key、AppID、Access Key 仅存在本机，绝不写入任务记录、播客 meta.json 或错误日志。

成品完全归你

合成的纯人声 MP3、单句缓存和对话字幕均存储在本地文件夹，不经过任何托管云服务中转。

极简可审计

Electron 桌面壳包裹纯 Node.js + Express 5 + 原生前端，支持端口顺延（3456–3475）与本地配置持久化，零外部 ffmpeg 依赖。

出厂安全门禁

构建脚本与 GitHub Actions 强制拦截密钥与本机路径泄露，每次发版均随带 SHA256SUMS.txt。
