ONBOARDING · 3 步下载即用

免装 Node.js，下载桌面客户端双击开播

v1.1.0 桌面正式版内置运行环境，支持自动端口避让（3456–3475）、本地配置持久化与一键导入旧版便携目录，无需命令行或编程环境。

1

下载对应系统桌面安装包

macOS 请按芯片选择 Apple Silicon (.dmg) 或 Intel (.dmg)，Windows 选择 64 位安装版 (.exe)；亦可在 GitHub Releases 获取便携 Node.js 版。

2

安装并首次放行开源未签名版

将「拾声集」拖入「应用程序」后首次打开，若遇「“拾声集”已损坏，无法打开」或「无法验证开发者」提示（既可能由未签名触发，也可能是文件损坏或被篡改），执行任何放行命令前请先确认安装包来自官方 Release，并核对同版本 SHA256SUMS.txt。确认无误后复制下方命令到终端回车，递归清除应用包扩展属性（含隔离标记）再重新双击打开（仅提示无法验证开发者时，也可在核验后前往「系统设置 → 隐私与安全性 → 仍要打开」）：

macOS 终端放行命令（先核对 SHA256 再执行）
xattr -cr "/Applications/拾声集.app"

双击 InkCast-v1.1.0-win-x64-setup.exe 完成安装；首次运行若遇「Windows 已保护你的电脑」提示，请先核对官方来源与 SHA256SUMS.txt，在设备策略允许且界面提供放行入口时，点击「更多信息 → 仍要运行」。

3

填好密钥、选风格，支持逐句微调

填入 API Key（语音可用免费 Edge 先试听），可选深度主讲 / 轻松对谈 / 正反交锋三种风格；生成后可逐句改词秒级重合成，也可一键导入旧版便携目录。

macOS Gatekeeper：提示“「拾声集」已损坏，无法打开”或“无法验证开发者”

该提示既可能是开源未签名触发的系统拦截，也可能表示文件损坏或被篡改。执行任何放行命令前，请先确认来自官方 Release 并核对同版本 SHA256SUMS.txt。核验无误并拖入「应用程序」后，在终端执行 xattr -cr "/Applications/拾声集.app" 递归清除已安装应用包的扩展属性（含系统隔离标记），再重新双击打开；若仅提示「无法验证开发者」，也可在核验后前往「系统设置 → 隐私与安全性 → 仍要打开」。

Windows SmartScreen：提示“Windows 已保护你的电脑”

因开源安装包未购买商业代码签名证书，SmartScreen 可能在启动安装程序或首次运行时拦截提醒。请先确认来自官方 Release 并对照同版本 SHA256SUMS.txt 核对校验和；在当前设备策略允许且界面提供放行入口时，点击弹窗里的「更多信息」→「仍要运行」。

凭据零落盘

API Key、AppID、Access Key 仅存在本机，绝不写入任务记录、播客 meta.json 或错误日志。

成品完全归你

合成的纯人声 MP3、单句缓存和对话字幕均存储在本地文件夹，不经过任何托管云服务中转。

极简可审计

Electron 桌面壳包裹纯 Node.js + Express 5 + 原生前端，支持端口顺延（3456–3475）与本地配置持久化，零外部 ffmpeg 依赖。

出厂安全门禁

构建脚本与 GitHub Actions 强制拦截密钥与本机路径泄露，每次发版均随带 SHA256SUMS.txt。
