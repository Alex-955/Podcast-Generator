# “AI妙听”双人播客生成器实施方案

## 1. 项目背景与目标
针对用户希望在非 OPPO 手机及电脑上随时将微信公众号文章、长文、网页或自定义文本转换成高品质“双人对话播客”的需求，打造一款极简好用、体验沉浸的 Web 全栈应用。

## 2. 大模型与 Token 成本分析
- **大模型推荐**：**DeepSeek-V3 / Chat**（性价比与中文表达巅峰）
  - 生成一期 3~5 分钟播客剧本大约消耗 **2,000 ~ 3,500 Tokens**。
  - 100 万 Tokens 大约可生成 **300 ~ 500 篇**长文播客。
  - 官方 API 成本单期仅约 **0.005 ~ 0.01 元人民币**（几乎相当于免费）。
- **阿里百炼 / 通义千问**：兼容 OpenAI 协议，适合有多余免费额度时切换。
- **系统支持**：在界面设置中支持随时切换 DeepSeek / 阿里百炼 / OpenAI 兼容接口，并支持本地持久化记住 API Key。

## 3. 技术架构设计

### 3.1 前端 (Vue 3 / React / 现代原生极简现代化 UI)
- **输入区**：支持直接粘贴微信文章/网页 URL（自动抓取正文），或直接粘贴纯文本/Markdown。
- **播客设置**：
  - 剧本风格：轻松闲聊、深度科普、商业分析、犀利吐槽。
  - 双人角色配置：主持人（引导/提问） + 嘉宾（拆解/洞见）。
  - 音色选择：支持云希、云扬、晓晓、晓涵等经典自然声音，预留高拟真商业音色。
  - BGM 氛围：精选轻音乐、Lo-Fi、科技轻松感等开场/背景音乐。
- **播放与沉浸展示**：
  - 类似小宇宙与 Apple Podcasts 的流线型播放器。
  - 双人对话气泡随音频播放**实时高亮滚动**。
  - 支持一键导出 MP3 文件、导出 Markdown 播客脚本文本。

### 3.2 后端服务 (Node.js + Express / Fastify)
- **网页解析器**：通过抓取引擎智能提取微信公众号、知乎专栏或普通文章的标题与正文（去广告、去噪音）。
- **播客剧本生成引擎**：精心调优的 Prompt，让角色自然接话、提出好问题、给出精彩洞见，非机械朗读。
- **TTS 语音合成服务**：
  - 基于 WebSocket / Node-Edge-TTS 实现微软高音质免 Key 语音合成。
  - 插件化 Provider 设计（预留 MiniMax、CosyVoice、OpenAI 等商业接口）。
- **音频处理引擎**：
  - 逐句音频合成缓存。
  - 音频拼接与轻量级 BGM 混音合成完整 MP3。

## 4. 实施阶段计划
1. **阶段一：后端核心链路打通**
   - 文章抓取解析模块（支持 URL 与纯文本）。
   - DeepSeek / 通用 LLM 播客剧本生成 Prompt 调优与 JSON 格式化输出。
   - Edge-TTS 高音质语音合成器（男声 + 女声）。
   - 音频缝合与 BGM 智能混音输出。
2. **阶段二：现代化全平台 Web 界面开发**
   - 响应式适配移动端（手机浏览器体验优良）与 PC 端。
   - 文章输入、一键生成进度可视化展示（抓取 ➔ 剧本 ➔ 配音 ➔ 混音）。
   - 双人播客互动播放器（进度条、倍速、双人角色气泡动态高亮）。
   - API Key 与音色偏好设置弹窗。
3. **阶段三：端到端验证与体验打磨**
   - 微信文章真实链接端到端测试。
   - 音质、断句、BGM 听感调优。
   - 提供便捷的启动命令与说明。
