### 1.1 核心状态机模型 (解耦 TaskStatus 与 PipelineStage)

UI 将**全局任务生命周期状态** (`TaskStatus`) 与**生成执行流水线阶段** (`PipelineStage`) 彻底解耦：

- **TaskStatus (任务整体状态)**:
  - `idle`: 待命态（可输入、可载入历史，播放器若无音频则禁用）。
  - `parsing`: 解析提取中（解析文章 URL 或校验正文）。
  - `confirmed`: 正文已确认待生成（展示文章标题、真实字数、预览展开）。
  - `running`: 正在流水线生成（展示阶段、耗时或 N/M 进度，提供“取消生成”按钮）。
  - `suspended`: 生成挂起中断（如 TTS 超时或限流，保留已完成分片，提供断点续跑）。
  - `failed`: 生成终止失败（不可恢复错误，提供重试或回退入口）。
  - `ready`: 播客音频与字幕就绪（播放器可用，可点击字幕联动播放）。

- **PipelineStage (流水线阶段)**:
  - `stage_1_extract`: 抓取与正文清洗。展示阶段耗时（如 `1.2s`），不展示伪百分比。
  - `stage_2_script`: 剧本重构与对谈分镜。展示阶段耗时（如 `2.4s`）。
  - `stage_3_tts`: 逐句语音合成。展示分母明确的进度文案（如 `正在合成第 3/6 句`），以及对应比例的进度条。若遇后端自动重试，展示重试等待状态（`正在进行第 2/3 次自动重试，已等待 12s...`）。
  - `stage_4_stitch`: 音频切片拼接与校验。展示阶段耗时（如 `0.6s`）。彻底收回未批准的“混音避让”承诺。

## 2. 前端 UI 数据契约定义 (候选契约，待工程对齐)

以下接口仅代表 UI 渲染与交互所需的字段子集，不限制后端传输包装格式：

```typescript
// 1. 解析确认卡所需数据
export interface ParsedArticleView {
  title: string;          // 文章标题（若来自正文粘贴，由前端取首行或生成默认标题）
  source: string;         // 来源说明（如 "微信公众号"、"手动粘贴正文"）
  charCount: number;      // 真实统计字数（严格按输入文本长度计算，不可固定硬编码）
  author?: string;        // 作者/发布方
  summary: string;        // 正文摘要（供卡片折叠/展开预览）
  isShort?: boolean;      // 字数过短警告标记 (< 50 字)
}

// 2. 剧本单句与字幕项
export interface ScriptLineView {
  index: number;          // 0-based 句子全局索引 (0, 1, 2, ...)
  role: 'host' | 'guest'; // 说话人: host(阿泽), guest(小晓)
  tone: string;           // 语气/情绪标签 (如 "好奇开场", "设问求索", "敏锐切入")
  text: string;           // 台词正文
  start: number;          // 起始秒数 (如 0.0)
  end: number;            // 结束秒数 (如 7.5)
}

// 3. 错误与中断数据
export interface StepErrorPayload {
  code: string;           // 业务错误码 (见第 3 节)
  message: string;        // 面向用户的友好错误描述
  failedStage: 'extract' | 'script' | 'tts' | 'stitch';
  failedIndex?: number;   // 仅 TTS 阶段出现: 0-based 失败句索引 (如 3 表示第 4 句)
  canResume: boolean;     // 是否支持断点续跑 (true 时展示断点续跑按钮)
  retryCount?: number;    // 当前已重试次数
  maxRetries?: number;    // 最大重试次数
}

// 4. 历史记录项
export interface HistoryTaskItem {
  id: string;             // 任务唯一标识
  title: string;          // 播客标题
  timeAgo: string;        // 相对时间 (如 "10分钟前")
  durationText: string;   // 格式化时长 (如 "01:15")
  durationSeconds: number;// 总秒数
  isCorrupted?: boolean;  // 模拟异常状态: 音频损坏/过期
  dialogues: ScriptLineView[]; // 完整独立的对白列表 (点击只载入，不重跑生成)
}
```

## 3. 错误码语义与前端恢复路径

| 业务错误码 | 触发阶段 | UI 表现 | 主动作恢复路径 | 辅助/演示动作 |
| :--- | :--- | :--- | :--- | :--- |
| `ERR_FETCH_ANTISPIDER` | 抓取阶段 | 弹出防爬拦截警示面板；流水线收起；确认卡严格隐藏 | 点击**“切换到正文粘贴”**：仅切换 Tab 并聚焦文本框，保持文本为空或已有草稿，**绝不自动伪造已解析成功** | 单列**“填入示例正文 (模拟演示)”**按钮，明确标注为演示数据，点击后用户可校验字数并点击解析 |
| `ERR_TTS_TIMEOUT` | 语音合成 | 步骤 3 标红挂起；展示“第 N 句连接超时，已自动重试 3 次” | 点击**“从断点续跑 (第 N 句)”**：继承已成功的前 N-1 句音频，仅续传剩余句子 | 点击**“取消生成”**终止任务 |
| `ERR_TTS_RATE_LIMIT` | 语音合成 | 步骤 3 标黄；展示“触发服务商并发限制，建议稍候重试” | 提供重试倒计时，倒计时结束后允许点击**“继续合成”** | 点击**“取消生成”**终止任务 |
| `ERR_AUDIO_MISSING` | 历史播放 | 播放器顶部弹出警告条；禁用播放按钮与滑块；字幕区展示异常 | 点击**“重新尝试加载”**检查本地文件是否存在 | 从列表切换其他有效历史 |

## 4. 真实 DOM 元素清单与无障碍属性

- 容器与工作区：
  - `#app-root`: 主应用容器
  - `#panel-input-stage`: 左侧编排工作区
  - `#panel-player-stage`: 右侧播放器与字幕广播室
- 表单与控制：
  - `#tab-url` / `#tab-text`: 输入模式切换选项卡 (`role="tab"`)
  - `#input-url`: URL 输入框 (绑有关联 `<label for="input-url">`)
  - `#input-raw-text`: 正文粘贴多行文本框 (绑有关联 `<label for="input-raw-text">`)
  - `#input-validation-msg`: 统一输入校验提示栏 (`role="alert"`)
  - `#btn-parse-article`: 解析触发按钮
- 确认与流水线：
  - `#box-confirm-article`: 正文确认卡片 (`display: none` 待触发)
  - `#confirm-word-count`: 真实字数检测值
  - `#confirm-short-warning`: 正文过短黄色警示
  - `#card-progress`: 流水线进度卡片
  - `#progress-phase-text`: 阶段文案（真实状态与耗时）
  - `#progress-retry-status`: 自动重试与等待状态行
  - `#btn-cancel-generation`: 任务运行中的“取消生成”按钮
  - `#box-error-callout`: 错误提示与恢复面板
  - `#btn-fallback-tab`: 防爬回退主动作（“切换到正文粘贴”）
  - `#btn-fallback-fill-demo`: 防爬回退演示动作（“填入示例正文 (模拟演示)”）
  - `#btn-resume-step`: TTS 断点续跑按钮
- 播放器与字幕：
  - `#player-error-banner`: 音频损坏/失效横幅
  - `#btn-play`: 主播放/暂停按钮 (`aria-label="播放"` / `"暂停"`)
  - `#audio-scrubber`: 播放进度条 (`role="slider"`)
  - `#list-dialogues`: 对话字幕流容器 (`role="feed"`)
  - `.dialogue-bubble`: 每一句字幕项 (使用可聚焦元素并支持 `Enter`/`Space` 触发跳播)
  - `.recent-task-item`: 历史条目按钮 (全部使用 `<button class="recent-task-item">`)
